PITWALL TELEMETRY ENGINE - ARCHITECTURAL EVOLUTION & v2 BLUEPRINT
---------------------------------------------------------------------------------

1. 📌 MILESTONES OVERVIEW:
   - v1 (COMPLETED on branch 'grafana'): 
     * Ingestion client (OpenF1), Pydantic v2 schemas, async replay at 10x with pause skipping.
     * Strategy inferences (deceleration Δv/Δt, heavy braking counter, DRS attack threat).
     * FIA Race Control track flags (Green, Yellow, Safety Car, Red Flag pit lane pause).
     * Redis 7 Streams message buffer (MAXLEN ~ 5000) with password auth.
     * Prometheus metrics exporter + Provisioned Grafana dashboard (1s poll).
     * Production containerization via Docker Compose & Cloudflare Tunnel.

   - v2 (ACTIVE on branch 'live-pitwall'):
     * Eliminates 1-second polling bottleneck by replacing Grafana with an on-demand, single-window 60 FPS web application.
     * FastAPI async backend serving REST endpoints & WebSockets (/ws/telemetry).
     * In-memory Redis 7 Stream buffer consumed directly by WebSocket manager.
     * Interactive On-Demand Playback: Grand Prix session picker, driver battle selector, Play/Pause/Restart buttons, and dynamic speed multiplier slider (1x - 50x).
     * 2D GPS Live Track Map (Canvas) with Min-Max normalized coordinates and moving car dots.
     * 60 FPS Physics Interpolation (lerp) for smooth-sweeping analog needles, fluid speed counters, and real-time throttle/brake waveforms.

2. ⚠️ REAL-WORLD F1 EDGE CASES TO ACCOUNT FOR IN v2:
---------------------------------------------------------------------------------
- Driver Retirements (DNF): Car crashes/stops mid-race. Detect DNF state so dot fades/disappears from 2D map.
- Lapped Drivers: Leaderboard sorting & intervals logic must parse string values like "+1 LAP" / "+2 LAPS" safely.
- Multi-Frequency Stream Synchronization: 
    * car_data (~10 Hz)
    * location X,Y,Z (~3.5 Hz)
    * intervals (~0.05 Hz per sector)
    * race_control flags (sparse events)
  Unified timeline clock/queue ensures non-blocking playback.
- Red Flag Suspensions: When all cars enter pit lane at 0 km/h, banner glows bright red and engine auto fast-forwards the 30-min pause in 3 seconds.
